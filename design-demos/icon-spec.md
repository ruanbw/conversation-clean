# ConversationClean 图标设计 Spec

## 产品背景
- **产品**：ConversationClean — macOS 原生应用
- **功能**：扫描并清理 15 款 AI 编码 Agent / IDE 遗留的会话数据
- **技术栈**：Swift 6 + SwiftUI，macOS 14.0+
- **目标用户**：开发者、AI 工具重度用户

## 设计需求
- **核心元素**：对话气泡 + 清洁元素（扫把/橡皮擦/删除线/ sparkle）
- **配色**：橙色系，AccentColor = #D98C00 (sRGB: 0, 0.55, 0.85)
- **气质**：专业简洁，macOS 原生感
- **形状**：macOS squircle（圆角矩形，连续曲率）
- **尺寸**：需展示 16x16 / 32x32 / 64x64 / 128x128 / 256x256 / 512x512

## 三个设计方向

### 方向 A — Flat Minimal（扁平极简）
- 纯色橙色背景（#D98C00），无渐变
- 白色对话气泡为主体，融入清洁符号（如气泡内的 sparkle 或气泡旁的扫把）
- 无阴影、无高光，完全扁平
- 参考：macOS 系统工具图标的简洁感

### 方向 B — Subtle Depth（微妙质感）
- 橙色渐变背景（从 #E89A00 到 #C77E00），微妙径向渐变
- 白色图形带极轻的投影（1-2px），有层次但不夸张
- 对话气泡 + 清洁元素，图形有微妙的立体感
- 参考：CleanMyMac X 的质感处理

### 方向 C — Modern Badge（现代徽章）
- 白色/浅灰背景，橙色图形
- 对话气泡用橙色填充，清洁元素用深橙/棕色
- 整体像一枚徽章/印章，有包裹感
- 参考：现代 macOS 图标的 badge 风格

## 技术要求
- 纯 HTML/CSS/SVG 实现，不依赖外部图片
- 每个方向生成一个 HTML 文件，展示图标在多个尺寸下的效果
- 图标必须是矢量清晰的（SVG 或 CSS 形状）
- 展示区域背景用中性灰/深色，模拟 macOS Dock 和 Finder 中的效果
